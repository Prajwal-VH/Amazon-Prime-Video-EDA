# Amazon Prime Video – Exploratory Data Analysis (EDA)

## Project Overview
This project explores the Amazon Prime Video content catalogue using Exploratory Data Analysis (EDA). The objective is to examine the distribution and characteristics of movies and TV shows and identify patterns that may support content planning and catalogue management.

## Business Objective
To analyze the available content data and understand patterns across content types, genres, release years, countries, age classifications, runtimes, and ratings. The findings can help stakeholders better understand the catalogue and identify areas for further investigation.

## Datasets
This project uses two CSV files:

- **`titles.csv`** – Contains information about titles available in the dataset.
- **`credits.csv`** – Contains cast and crew information associated with titles.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow
1. Load and inspect the datasets.
2. Examine data types and missing values.
3. Clean and prepare the data for analysis.
4. Perform exploratory data analysis.
5. Create visualizations to investigate content patterns.
6. Interpret chart findings and discuss potential business implications.

## Areas of Analysis
- Movies and TV show distribution
- Genre representation
- Content release years
- Production country distribution
- Age classifications and ratings
- Runtime patterns
- Cast and crew information

## Key Takeaways
The analysis provides a structured overview of the content represented in the datasets. The visualizations help explore catalogue composition and identify patterns that may be useful for further analysis and content planning.

The datasets do not directly establish title popularity, viewership, profitability, or audience satisfaction. Additional engagement and business data would be required to evaluate these outcomes.

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Ensure `titles.csv` and `credits.csv` are available at the file paths expected by the notebook.
5. Run the notebook cells in order.

## Project Files

## Conclusion
This project demonstrates how exploratory data analysis and data visualization can be used to examine a streaming platform's content catalogue, identify patterns, and generate questions for further business analysis.
